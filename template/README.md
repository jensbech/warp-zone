# warp profile

This directory is a warp-zone profile, generated by `just new` and refreshed from the repo on every `open`, `build`, `rebuild`, `ssh` and `restore`. Run commands through `just` or `warp` from anywhere (`warp open <name>`), not from here.

Your settings are in `profile.env`; apply edits with `just rebuild <name>`. `setup.sh` is yours: a root build hook for anything the tool catalog cannot express. Everything else is managed and will be overwritten.

| File | Role |
| --- | --- |
| `profile.env` | Settings: `TOOLS`, `EXTRA_APT_PACKAGES`, version pins, CPU/memory, SSH, dotfiles, `DOCKERD_ARGS` |
| `setup.sh` | Optional root build hook |
| `Dockerfile`, `catalog.json`, `install-tools.sh` | Image definition, tool catalog and its installer |
| `warp-init`, `bootstrap-home`, `templates/` | Container init (dockerd, sshd) and home/shell setup |
| `build.sh`, `open.sh`, `rebuild.sh`, `ssh.sh`, `lib/` | Scripts behind the `just` commands |
| `backups/` | `~/work` tarballs from `just backup` |

See the repository README for the full command list.
